# Прокси для Telegram

## Цель

Развернуть на своём VPS прокси для обхода блокировок Telegram. Прокси будут использовать владелец и его друзья.

## Требования

- Запуск через Docker Compose: после первоначальной настройки достаточно выполнить `docker compose up -d`.
- Подключение из приложений Telegram по ссылке, которую можно отправить друзьям.
- Секреты и настройки должны сохраняться при пересоздании контейнера. Секреты не должны попадать в репозиторий.
- У каждого пользователя свой секрет. Создание секретов и получение ссылок выполняются командой на VPS по SSH.
- Контейнер должен работать с минимально необходимыми правами. Конфигурацию монтируем только для чтения; для данных используем отдельную директорию.
- Используем только монтирование файлов и директорий хоста; Docker volumes не используем.
- Прокси принимает подключения на настраиваемом TCP-порту, по умолчанию 443. Порт должен быть свободен и доступен извне на VPS.
- Решение должно вписываться в стиль репозитория: отдельная директория с `docker-compose.yml` и краткой инструкцией по запуску и подключению.

## Вариант реализации

`MTProxy` — прокси для подключений клиентов Telegram. Для маскировки трафика рассматривается режим `Fake TLS`. Он может помочь при блокировках, но не гарантирует обход всех способов фильтрации.

Выбрана [Telemt](https://github.com/telemt/telemt) — сторонняя реализация MTProxy с поддержкой Fake TLS и Docker Compose. Фиксируем версию [3.5.16](https://github.com/telemt/telemt/releases/tag/3.5.16), актуальную на момент выбора; доступность соответствующего образа нужно проверить при реализации. Перед реализацией нужно проверить, как в ней организованы первоначальная настройка, сохранение секретов и получение ссылок.

Для Fake TLS пока используем `github.com` как домен маскировки. При включённой пересылке посторонних подключений Telemt может направлять их на GitHub; доступность и поведение необходимо проверить после настройки.

Существующий `telegram_bot_proxy` обслуживает HTTP-запросы к Telegram Bot API и для подключения приложений Telegram не подходит.
